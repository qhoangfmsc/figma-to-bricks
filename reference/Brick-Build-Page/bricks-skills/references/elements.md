# Element Catalog

Every element name registered in Bricks 2.4.2 (`includes/elements.php` — 85 elements excluding WooCommerce), with the settings that matter for JSON authoring. Style every element with the universal `_` keys from style-settings.md; this file covers element-specific keys. Control keys below were checked against `includes/elements/<name>.php` of 2.4.2.

## Registry

**Layout (nestable):** `section` `container` `block` `div`
**Basic:** `heading` `text-basic` `text` (rich) `text-link` `button` `icon` `image` `video` `svg` `logo` `divider` `list` `alert` `html` `code` `shortcode` `template`
**Nestable interactive:** `accordion-nested` `tabs-nested` `slider-nested` `nav-nested` `dropdown` `offcanvas` `toggle` `toggle-mode` `slot`
**Media:** `image-gallery` `audio` `file` `carousel` `instagram-feed` `facebook-page`
**Internal (hidden from the panel, generated by WooCommerce Checkout):** `form-checkbox`
**Marketing:** `icon-box` `social-icons` `pricing-tables` `counter` `countdown` `progress-bar` `pie-chart` `team-members` `testimonials` `animated-typing` `rating` `back-to-top`
**Forms & search:** `form` `search`
**WordPress:** `wordpress` `posts` `nav-menu` `sidebar` `breadcrumbs`
**Single post:** `post-title` `post-excerpt` `post-content` `post-meta` `post-author` `post-comments` `post-taxonomy` `post-navigation` `post-sharing` `post-toc` `post-reading-time` `post-reading-progress-bar` `related-posts`
**Query:** `pagination` `query-results-summary`
**Query filters (require the Query Filters feature):** `filter-search` `filter-select` `filter-checkbox` `filter-radio` `filter-range` `filter-datepicker` `filter-submit` `filter-active-filters`
**Maps:** `map` `map-leaflet` `map-connector`
**Legacy (avoid in new builds — use the `-nested` versions):** `accordion` `tabs` `slider`
**WooCommerce:** see woocommerce.md

## Layout Elements

`section` → root-level wrapper (renders `<section>`, inner width constrained by theme style). `container` → max-width inner wrapper. `block` → full-width flex div. `div` → unstyled div (no default width/display).

| Setting | Values | Notes |
|---------|--------|-------|
| `tag` | `section` `div` `header` `footer` `nav` `main` `article` `aside` `figure` `custom` | semantic HTML — use it |
| `customTag` | any tag | when `tag: "custom"` |
| `link` | link object | makes the whole element a link |
| `hasLoop` + `query` | see query-loops.md | turns the element into a query loop |
| `_shapeDividers` | see style-settings.md | section decorations |

Standard page skeleton:

```json
{ "id": "sec001", "name": "section", "parent": 0, "children": ["con001"], "settings": { "tag": "section" } }
{ "id": "con001", "name": "container", "parent": "sec001", "children": ["..."], "settings": {} }
```

Sections stack vertically at root. Inside a container, use `block`/`div` with `_display` flex or grid for columns/grids — there is no "column" element.

## Content Elements

### heading
```json
{ "text": "Build faster", "tag": "h2" }
```
`tag`: `h1`–`h6` | `custom`. Optional separator: `separator` (`right` `left` `both`), `separatorWidth/Height/Spacing/Style/Color/AlignItems`. `link` object makes it a link. Style size via `_typography`.

### text-basic — single paragraph/span (preferred for plain text)
```json
{ "text": "One paragraph of plain text.", "tag": "p" }
```
`tag`: `p` (default) | `span` | `div` | `custom`/`customTag`. `wordsLimit` + `readMore` for trimming.

### text — rich text (multiple paragraphs, HTML)
```json
{ "text": "<p>First.</p><p>Second with <strong>bold</strong>.</p><ul><li>Item</li></ul>" }
```
HTML allowed. Use for multi-paragraph content; use `text-basic` otherwise.

### button
```json
{
  "text": "Get started",
  "tag": "a",
  "link": { "type": "external", "url": "#pricing" },
  "style": "primary",
  "size": "lg",
  "icon": { "library": "themify", "icon": "ti-arrow-right" },
  "iconPosition": "right",
  "iconGap": "8px"
}
```
- `style`: `primary` `secondary` `light` `dark` `muted` `info` `success` `warning` `danger` (theme-style colors). **Omit `style` entirely for fully custom-styled buttons** and use `_background`/`_typography`/`_border` instead.
- `size`: `sm` `md` `lg` `xl`; `outline: true`; `circle: true`
- `tag`: `a` (default when link set) | `button` — use `button` + interactions for non-navigation actions.

### image
```json
{
  "image": { "id": 123, "url": "https://site.com/photo.jpg", "size": "large" },
  "altText": "Team at work",
  "loading": "lazy",
  "link": { "type": "lightbox" }
}
```
Dynamic: `"image": { "useDynamicData": "{featured_image}", "size": "large" }`. Caption: `caption`: `none` | `attachment` | `custom` (+ `captionCustom`). Lightbox settings under `lightbox*`. Object-fit cropping: set `_height`/`_aspectRatio` + `_objectFit: "cover"` (`_objectPosition` to focus).

### icon
```json
{ "icon": { "library": "ionicons", "icon": "ion-ios-checkmark-circle" }, "iconSize": "32px", "iconColor": { "hex": "#16a34a" } }
```
Libraries: `themify`, `ionicons`, `fontawesomeRegular/Solid/Brands`, `svg` (`{ "library": "svg", "svg": { "id": 1, "url": "..." } }`).

### icon-box
`icon` (icon object), `iconSize`, `iconColor`, `direction` (`row` = icon left, `column` = icon top; `iconPosition` is deprecated), `content` (HTML), `gap`, plus `icon*`/`content*` style sub-keys. For full control, build your own with `div` + `icon` + `heading` + `text-basic` instead.

### social-icons
Repeater key is `icons`: `[{ "id": "...", "label": "X", "icon": {...icon object}, "link": {...link object}, "iconColor"?, "iconSize"? }]`. Top-level: `iconColor`, `iconSize`, `gap`, `direction`.

### divider
`style` (`solid` `dashed` `dotted` `double`), `direction` (`horizontal`/`vertical`), `width`, `height` (thickness), `color`, `justifyContent`, optional `icon` + `iconPosition` (`left` `center` `right`) + `iconSpacing`.

### list
Repeater `items`: `[{ "title": "...", "description": "...", "link": {...} }]` plus `icon`, `iconColor`. For custom layouts prefer a `ul`-tagged `div` with children.

### video
Source switch is **`videoType`**: `youtube` (default) | `vimeo` | `media` (library, key `media`) | `file` (URL) | `meta` (dynamic data).
- YouTube: `{ "videoType": "youtube", "youTubeId": "dQw4w9WgXcQ", "youtubeControls": true, "youtubeRel": false }`
- Vimeo: `{ "videoType": "vimeo", "vimeoId": "76979871" }`
- File URL: `{ "videoType": "file", "fileUrl": "https://.../clip.mp4", "fileControls": true, "fileLoop": true, "fileMute": true, "fileInline": true, "videoPoster": {image} }`
- Facade (load iframe on click): `previewImage: "default"` (YouTube/Vimeo API thumbnail) or `"custom"` + `previewImageCustom`; `overlay` (background object) + `overlayIcon`.
- `aspectRatio` uses a slash: `"16/9"` `"9/16"` `"4/3"` `"3/4"` `"21/9"` `"1/1"` `"2/3"` `"3/2"`; `iframeTitle` for accessibility.

### svg
`source`: omit (= library file, key `file` = `{ "id", "url" }`) | `iconSet` (+ `iconSet` icon object) | `dynamicData` (+ `dynamicData` tag) | `code` (+ `code`). `code` is **signed** by Bricks — pasted unsigned SVG code does not render until an admin re-signs it, so prefer `iconSet` or `file` in generated JSON. Style: `width`, `height`, `strokeWidth`, `stroke`, `fill`, optional `link`.

### logo / nav-menu / sidebar / search
- `logo`: `logo` (image), `logoInverse` (sticky-header swap), `logoText` fallback, `logoWidth/Height`, `logoUrl`
- `nav-menu`: `menu` (WP nav menu term ID, site-specific — leave empty in patterns), `menuAlignment`, `menuGap`, `menuTypography`, `menuActiveTypography`, `subMenu*` styling, `mobileMenu` (breakpoint key or `always`/`never`), `mobileMenuPosition` (`right`/`left`), `mobileMenuBackground` — prefer `nav-nested` for new builds
- `search`: `searchType` (`input` | `overlay`), `placeholder`, `ariaLabel`, `buttonText`/`icon`, `showLabel` + `labelText`, `actionURL`, repeater `additionalParams` `[{ "paramKey": "post_type", "paramValue": "post" }]` (hidden inputs), overlay: `searchOverlayTitle`, `searchOverlayBackground`
- `breadcrumbs`: `homeLabel`, `homeIcon`, `hideHomeLabel`, `separatorType` (`text` `icon` `none`) + `separatorText`/`separatorIcon`, `gap`, `itemTypography`, `currentItemTypography`; repeater `singularStructure` (`postType[]`, `showTaxonomy` + `taxonomy`, `showParentPosts`, `showPostTypeArchive`) customizes the trail per post type

### counter / countdown / progress-bar / pie-chart / rating / animated-typing
- `counter`: `countFrom`, `countTo`, `duration` (ms), `prefix`, `suffix`, `thousandSeparator` + `separatorText`, `countTypography`
- `countdown`: `date` (`"2026-12-31 23:59"`), `timezone` (`"UTC+07:00"`), repeater `fields`: `[{ "prefix"?, "format": "%D", "suffix": " days" }]` (`%D %H %M %S`, lowercase drops leading zero), `action` on finish (`countdown` `hide` `text` + `actionText`), `flexDirection`, `gutter` (spacing object = margin of each field, e.g. `{ "right": "20px" }`), `typography` / `typographyPrefix` / `typographySuffix`
- `progress-bar`: repeater `bars`: `[{ "title": "SEO", "percentage": 80, "color"?: {color} }]`, `height`, `barSpacing`, `showPercentage`, `barColor`, `barBackgroundColor`
- `pie-chart`: `percent`, `size`, `lineWidth`, `lineCap` (`butt` `round` `square`), `content` (`percent` `icon` `text` + `icon`/`text`), `barColor`, `trackColor`, `scaleLength`
- `rating`: `rating` (e.g. `4.5`), `maxRating`, `icon`, `iconColorFull`, `iconColorEmpty`, `iconSize`, `gap`; `schema: true` + `schemaType`, `schemaName`, `reviewAuthor` outputs Review JSON-LD
- `animated-typing`: `tag`, `prefix`, `suffix`, repeater `strings` `[{ "text": "design" }]`, `typeSpeed`, `backSpeed`, `startDelay`, `backDelay`, `cursorChar`, `loop`, `shuffle`

### alert / html / code / shortcode / template
- `alert`: `content` (HTML), `type` (`info` `success` `warning` `danger` `muted`), `dismissable`
- `html`: `html` (raw markup, no PHP)
- `code`: `code` + `prettify` theme for display-only snippets; `executeCode: true` runs HTML/CSS/JS/PHP. Code is **signed** — pasted code must be re-signed by an admin before it executes; avoid generating executable code
- `shortcode`: `shortcode` (`"[contact-form-7 id=\"5\"]"`), `showPlaceholder` in builder
- `template`: `template` (section/content/popup template post ID — site-specific), `noRoot` to render without wrapper

### sidebar / wordpress
- `sidebar`: `sidebar` (registered sidebar id, e.g. `"sidebar-1"`), `titleTypography`, `contentTypography`
- `wordpress` (core widgets): `type` (`posts` `archives` `calendar` `categories` `pages` `comments` `tagCloud` `taxonomy`), `title` + `titletag`, `postsNumber`, `postsDate`, `postsFeaturedImage`, `showCount`, `taxonomy` (for `taxonomy` type)

### image-gallery / carousel
- `image-gallery`: `items` = `{ "images": [ { "id": 123, "url": "...", "full": "..." } ], "size": "large" }` or `{ "useDynamicData": "{acf_gallery}" }`; `layout` (`grid` `masonry` `metro`), `columns`, `gutter`, `imageRatio`, `link` (`lightbox` `attachment` `media` `custom`), `lightboxThumbnails`, `caption`, `loadMoreInitial`/`loadMoreStep`
- `carousel` (Swiper): `type` `media` (+ `items` as above) or `posts` (+ `query` + repeater `fields` `[{ "dynamicData": "{post_title:link}", "tag": "h3" }]`); `slidesToShow`, `slidesToScroll`, `gutter`, `height`, `effect`, `infinite`, `autoplay` + `autoplaySpeed`, `pauseOnHover`, `speed`, `arrows`, `dots`, `imageSize`, `imageLightbox`. Breakpoint keys work (`slidesToShow:mobile_portrait`). Prefer `slider-nested` for custom slide markup

### audio / file / instagram-feed / facebook-page
- `audio`: `source` (`file` library | `external` + `external` URL | `dynamic` + `useDynamicData`), `title`/`titleCustom`, `artist`, `autoplay`, `loop`, `preload`, `theme` (`light` `dark`)
- `file` (download/PDF preview, 2.4+): `source` (`file` + `file` = `{ "id", "url", "filename", "mime" }` | `external` + `external` | `dynamic`), `customFileName`, `downloadButtonText`, `buttonStyle`, `openInNewTab`, `hidePdfPreview`, `previewHeight`, `previewLoadOnInteraction`
- `instagram-feed`: access token lives in Bricks → Settings → API keys (not in element JSON); `numberOfPosts`, `columns`, `imageGap`, `imageAspectRatio`, `imageLink`, `caption`, `followText`, `followPosition` (`top` `bottom`), `cacheDuration`
- `facebook-page`: `href` (page URL), `tabs` (`timeline` `events` `messages`), `width`, `height`, `smallHeader`, `hideCover`, `hideCta`, `profilePhotos`

### map / map-leaflet / map-connector
- `map` (Google — API key in Bricks → Settings → API keys): `addresses` repeater `[{ "address": "Hanoi, Vietnam" }]` or `[{ "latitude", "longitude" }]`, `zoom`, `height`, `type` (`roadmap` `satellite` `hybrid` `terrain`), `renderMode` (`api` | `iframe` — iframe works without key and reads the single `address` key instead of the `addresses` repeater; 2.4.2+), `markerCluster`, `scrollwheel`, `draggable`, `zoomControl`, `googleMapId`. Sync with a query loop: `syncQuery` = loop element id (the loop then holds `map-connector` children)
- `map-leaflet` (OpenStreetMap, no key): `center` (`"lat, lng"`), `zoom`, `height`, `layers` `[{ "name": "OpenStreetMap", "url": "https://tile.openstreetmap.org/{z}/{x}/{y}.png", "attribution": "..." }]`, `markers` `[{ "coordinates": "lat, lng", "label": "..." }]`, `scrollWheelZoom` (`"true"` `"center"` `"false"`), `markerIcon`
- `map-connector`: place inside the query loop that `map.syncQuery` points at; per-item `latitude`/`longitude` or `address` (dynamic data such as `{acf_lat}`), optional `infoBoxTemplateId`. Renders an invisible `<template>` with location data

### back-to-top / toggle-mode
- `back-to-top` (nestable; default children `icon` + `text`): `position` (`fixed`), `positionRight`/`positionBottom`, `visibleAfter` (px scrolled), `visibleOnScrollUp`, `smoothScroll`, `moveFocusToTop`, `ariaLabel`
- `toggle-mode` (light/dark switch, 2.2+): `icon` + `iconColor` (light state), `iconDark` + `iconDarkColor`, `iconSize`, `ariaLabel`. Requires a color palette with dark-mode values to have visible effect

## Nestable Patterns (exact structure required)

Nestables ship structural CSS classes via the **`_hidden` settings key** — keep these intact or styling/scripts break:

```json
"settings": { "_hidden": { "_cssClasses": "accordion-title-wrapper" } }
```

### accordion-nested
Element settings: `expandFirstItem`, `independentToggle`, `faqSchema` (bool — outputs FAQ JSON-LD), `transition`, title/content style keys.
Each item child is:

```
block (Item)
├── block  settings._hidden._cssClasses = "accordion-title-wrapper"   (_direction row, _justifyContent space-between, _alignItems center)
│   ├── heading  { "text": "Question?", "tag": "h3" }
│   └── icon     { "icon": {...}, "isAccordionIcon": true }
└── block  settings._hidden._cssClasses = "accordion-content-wrapper"
    └── text     { "text": "<p>Answer.</p>" }
```

### tabs-nested
Element settings: `openTab` (index, `"0"` = first), `openTabOn` (`click` | `mouseenter`), `direction` (row = horizontal tabs), `titleWidth`, `titlePadding`, `titleBackgroundColor`, `titleBorder`, `titleActiveBackgroundColor`, `titleActiveBorder`, `contentPadding`, `contentBorder`. Structure:

```
tabs-nested
├── block (Tab menu)      _hidden._cssClasses = "tab-menu"      (_direction row)
│   ├── div (Title)       _hidden._cssClasses = "tab-title"     → children: text-basic "Tab 1"
│   └── div (Title)       _hidden._cssClasses = "tab-title"     → children: text-basic "Tab 2"
└── block (Content)       _hidden._cssClasses = "tab-content"
    ├── block (Pane)      _hidden._cssClasses = "tab-pane"      → children: any
    └── block (Pane)      _hidden._cssClasses = "tab-pane"      → children: any
```

Title count must equal pane count, in order.

### slider-nested (splide.js)
Element settings: `type` (`slide` `loop` `fade`), `perPage`, `perMove`, `gap`, `speed`, `autoplay`, `interval`, `pauseOnHover`, `height`, `arrows` + `arrow*` styling (`arrowColor`, `arrowBackground`…), `pagination` (dots, checkbox) + `paginationColor`/`paginationColorActive`/`paginationSpacing`. Breakpoint-responsive: `perPage:tablet_portrait` etc.
Children: each slide is a plain `block` (any content inside). Optional `splideJson` for raw splide config.

### nav-nested (accessible nav with mobile menu)
Children are free-form: `text-link` items, `dropdown` elements (each dropdown: `text` + children = its menu), `toggle` (hamburger). Key settings: `menuAlignment`, `mobileMenu` (breakpoint key at which nav collapses, e.g. `tablet_portrait`), `ariaLabel`, dropdown styling keys (`dropdownBackgroundColor`, `dropdownPadding`, …).

### dropdown
`text` (label), children render inside the dropdown content. `caret` settings included.

### offcanvas
Settings: `direction` (`top` `right` `bottom` `left`), `effect` (`slide` `offset`), `width` / `height`, `closeOn` (`backdrop` `esc` `none`), `noScrollBody`, `scrollToTop`, `noAutoFocus`, `openByDefault`, `transitionDuration`, `ariaLabel`. Structure:

```
offcanvas
├── block (Content)    _hidden._cssClasses = "brx-offcanvas-inner"     → any content + a close `toggle`
└── block (Backdrop)   _hidden._cssClasses = "brx-offcanvas-backdrop"  → no children (delete to disable)
```

Open it with a `toggle` outside the offcanvas whose `toggleSelector` targets it. Element ids regenerate on paste, so give the offcanvas a `_cssId` and target `#that-id`.

### toggle
`toggleSelector` (CSS selector of the target, default `.brxe-offcanvas` — set an explicit `#id` when the page has more than one offcanvas), `toggleAttribute` + `toggleValue` (attribute toggled on the target, default `class` / `brx-open`), `animation` (hamburger animation: `boring` `arrow` `minus` `spin` `squeeze` `vortex` …), `icon` (replaces hamburger), `barColor`, `barHeight`, `barScale`, `ariaLabel`.

## Posts element vs query loop

The `posts` element is a legacy all-in-one grid (settings: `query`, `layout` (`list` `grid` `masonry` `metro`), `columns`, `gutter`, `imageDisable`, `imageLink`, repeater `fields` `[{ "dynamicData": "{post_title:link}", "tag": "h3" }]`). **Prefer a `block`/`div` with `hasLoop` + `query`** (see query-loops.md) — it gives full layout control and works with query filters.

`related-posts` shares the field shape but its repeater key is `content`; query via `count`, `orderby`, `order`, `taxonomies` (`["category", "post_tag"]`), layout via `columns`, `gap`, `imagePosition`, `_aspectRatio`.

### Single post elements (use inside `single` templates)
- `post-title`: `tag` (default `h1`), `linkToPost`, `prefix`/`suffix`
- `post-excerpt`: `length` (words), `more`, `keepHTML`
- `post-content`: no content settings — renders the post body (Bricks or WP editor)
- `post-meta`: repeater `meta` `[{ "dynamicData": "{author_name}" }, { "dynamicData": "{post_date}" }]`, `separator`, `gutter`, `direction`
- `post-taxonomy`: `taxonomy` (default `post_tag`), `style` (theme button style, default `dark`), `size`, `gap`, `separator`, `linkDisable`
- `post-author`: `avatar`, `avatarSize`, `avatarPosition`, `name`, `website`, `bio`, `postsLink` + `postsText`
- `post-comments`: `source` (`bricks` `wordpress`), `title`, `avatar`, `formTitle` + `formTitleText`, `label`, `cookies`, `submitButtonText`
- `post-navigation`: `label` + `prevLabel`/`nextLabel`, `title`, `image` + `imageSize`, `inSameTerm` + `taxonomy`
- `post-sharing`: repeater `items` `[{ "service": "facebook" }]` (`facebook` `twitter` `linkedin` `whatsapp` `pinterest` `telegram` `vkontakte` `bluesky` `email`), `brandColors`, `direction`, `newTab`
- `post-toc`: `contentSelector` (default `.brxe-post-content`), `headingSelectors` (`"h2, h3"`), `collapseInactive`, `sticky` + `stickyTop`, `headingsOffset`
- `post-reading-time`: `prefix` (default `"Reading time: "`), `suffix` (default `" minutes"`), `calculationMethod` (`words` `characters`), `wordsPerMinute`
- `post-reading-progress-bar`: `barPosition` (`top` `bottom` `custom`), `barHeight`, `barColor`, `barBackgroundColor`, `contentSelector`

## Element defaults to remember

- Headings inherit theme-style typography — only set `_typography` when diverging.
- `button` `style` keys map to theme-style button colors; omit for custom.
- Every text-bearing setting accepts dynamic data tags: `"text": "{post_title}"`.
- `label` on the node (not in settings) names it in the structure panel — label everything in generated layouts.
