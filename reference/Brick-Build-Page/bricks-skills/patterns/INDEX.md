# Pattern Index

Ready-to-use Bricks JSON, grouped by folder. Two formats:

- **Clipboard** files (`"source": "bricksCopiedElements"`) — copy file contents, paste into the builder structure panel (Cmd/Ctrl+V).
- **Template** files (`"type": "header" | "footer" | "popup" | "single" | "archive" | "search" | "error"`) — import via Bricks → Templates → Import.

| Group | What's inside |
|-------|---------------|
| [sections/](sections/INDEX.md) | Page sections: heroes, logo strip, feature grid, pricing, testimonials slider, FAQ, CTA, contact |
| [templates/](templates/INDEX.md) | Header, footer, popup, single post, archive, search results, 404 |
| [query/](query/INDEX.md) | Query loops and faceted filters (ACF repeater, filterable archive, full filter sidebar) |
| [bem/](bem/INDEX.md) | Class-first BEM builds — zero inline styles on elements |
| [elements/](elements/INDEX.md) | One example per remaining element (tabs, offcanvas, counters, media, maps, embeds…) |


## Adapting patterns

- Colors are plain hex/rgba — swap for the site's palette ids or `var(--…)` raw values.
- ACF patterns assume field names noted in element labels; rename tags to the real fields.
- Element ids are namespaced per file and regenerate on import; safe to combine multiple patterns into one page by concatenating their `content` arrays (keep ids unique) and merging `globalClasses`.
- Files marked ⚠ in a group INDEX need a site-specific value after paste (API key, menu, sidebar, template, CPT, URL).
